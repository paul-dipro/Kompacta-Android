# Kompacta 📄

### Scan. Shrink. Submit.

**Kompacta** is a planned Android application designed to make document preparation simple, fast, and accessible.

The goal is to help users scan documents, convert photographs into PDFs, and automatically optimize files to meet specific size requirements—all through one simple workflow.

> 🚧 **Project Status: Planning & Initial Development**

## 💡 The Idea

Ever struggled to upload a PDF because it exceeded the maximum file-size limit?

Kompacta aims to solve this problem by bringing document scanning, PDF creation, and intelligent file-size optimization together in one application.

## ✨ Planned Features

- 📷 **Document Scanner** — Capture document pages using your phone.
- 📑 **Photo to PDF** — Combine multiple photographs into a single PDF.
- 🎯 **Smart Compression** — Automatically optimize files toward a specified size limit.
- 🧠 **Intelligent Optimization** — Balance file size, image resolution, and readability.
- ✅ **Submission Checks** — Validate supported requirements before sharing.
- 📤 **Save & Share** — Easily save and share prepared documents.
- 🔒 **Privacy-Conscious Design** — Prioritize on-device processing wherever practical.

*These features are planned and have not necessarily been implemented.*

## 🎯 The Vision

**Prepare → Optimize → Verify → Submit**

Kompacta aims to eliminate the need to switch between multiple applications just to prepare a document for an online form, college assignment, or job application.

The final implementation will evolve as development progresses.

## 🎓 Why This Project?

Kompacta is being developed as a hands-on Computer Science project to explore Android development, image processing, algorithm design, file handling, and practical software engineering.

The goal is to build a useful application while understanding the technology behind it.
